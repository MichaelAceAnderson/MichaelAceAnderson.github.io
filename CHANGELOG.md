# Journal des modifications

Tous les changements notables de ce projet seront documentés dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), et ce projet adhère à [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Principes directeurs :

- Les journaux de modifications sont pour les humains, pas pour les machines.
- Il devrait y avoir une entrée pour chaque version.
- Les mêmes types de changements doivent être regroupés.
- Les versions et les sections doivent être liées.
- La dernière version vient en premier.
- La date de sortie de chaque version est affichée.
- Mentionnez si vous suivez Semantic Versioning.

Types de changements :

- `Added` pour les nouvelles fonctionnalités.
- `Modified` pour les changements dans les fonctionnalités existantes.
- `Deprecated` pour les fonctionnalités bientôt supprimées.
- `Removed` pour les fonctionnalités maintenant supprimées.
- `Fixed` pour toute correction de bug.
- `Security` en cas de vulnérabilités.
