## Introduction

Ce portfolio est un projet personnel qui présente mes compétences, mes projets et mes expériences professionnelles. Les bonnes pratiques ont été utilisées pour garantir la qualité du code et la maintenabilité du projet. Le site est responsive et s'adapte à tous les écrans. Il aspire également à être optimisé pour le référencement naturel (SEO) et respecter les normes d'accessibilité (WCAG).

⚠️ **Note** : Ce projet n'est développé que par une personne, mais il est, à titre démonstratif, documenté et géré comme un projet d'équipe.
